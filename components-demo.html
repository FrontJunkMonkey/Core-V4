ReadMore Text Truncation

This is a long text that demonstrates the automatic text truncation feature. When text exceeds the specified number of lines, Core4 automatically adds a "Read more" button. This text is intentionally long to show how the truncation works. You can click the "Read more" button to expand the full text. This feature is perfect for product descriptions, blog previews, or any content where you want to show a preview but allow users to expand for more details. The truncation is responsive and works across all device sizes.
